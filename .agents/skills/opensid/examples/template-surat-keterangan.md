# Contoh Template Surat Keterangan Usaha (Format ODT)

Di bawah ini adalah contoh susunan teks untuk berkas LibreOffice Writer (`.odt`):

```text
PEMERINTAH KABUPATEN [nama_kabupaten]
KECAMATAN [nama_kecamatan]
KANTOR DESA [nama_desa]
Alamat: [alamat_kantor] Kode Pos: [kode_pos]
====================================================================

SURAT KETERANGAN USAHA
Nomor: [format_nomor_surat]

Yang bertanda tangan di bawah ini Kepala Desa [nama_desa], Kecamatan [nama_kecamatan], Kabupaten [nama_kabupaten], dengan ini menerangkan bahwa:

Nama Lengkap           : [nama]
NIK                    : [nik]
No. KK                 : [no_kk]
Tempat, Tanggal Lahir  : [tempatlahir], [tanggallahir]
Jenis Kelamin          : [sex]
Agama                  : [agama]
Pekerjaan              : [pekerjaan]
Alamat                 : [alamat], RT [rt] / RW [rw], Dusun [dusun]

Berdasarkan data yang ada pada kami dan sepengetahuan kami, nama tersebut di atas benar-benar memiliki usaha:

Nama Usaha    : [keterangan]
Lokasi Usaha  : Desa [nama_desa], Kecamatan [nama_kecamatan]

Demikian surat keterangan ini kami buat dengan sebenarnya agar dapat dipergunakan sebagaimana mestinya.


[nama_desa], [tgl_surat]
Kepala Desa [nama_desa]



[nama_penandatangan]
NIP. [nip_penandatangan]
```
