## Aturan Verifikasi
- OpenSID Free menggunakan branch `umum`.
- Jangan berasumsi fitur OpenSID Premium ada pada OpenSID Free.
- Tag rilis OpenSID Free menggunakan format rilis bulanan/tahun (misal `v2408.0.0`).
